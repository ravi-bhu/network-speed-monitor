Privacy

Network Speed Monitor keeps everything on your PC. It makes no network connections and sends nothing anywhere.

The app

No network connections
The app never connects to the internet or to any other computer. It only reads the byte counters Windows already keeps for your network adapters. It doesn’t import any Windows networking library (Winsock, WinHTTP, WinINet or URLMon), and every release is checked for that before it’s published. The Source code link in Settings opens GitHub in your browser; the app itself doesn’t fetch it.
No telemetry
No analytics, no crash reports, no update checks, no accounts.
Where your data is
A usage history database, usage.db, and a settings file, settings.ini, in %LOCALAPPDATA%\NetworkSpeedMonitor.
What the history holds
Bytes received and sent per hour, rolled up to days after 90 days. With each row: the adapter’s name and type, and the name Windows gives the network it was connected to, where Windows provides one. For Wi-Fi that’s usually the network’s name (its SSID); wired and other networks get a name from Windows too. It doesn’t record what you browse, which apps used the traffic, or any content.
Damaged history
If the database is ever found damaged, the app moves it aside as usage.corrupt-<date and time>.db in the same folder and starts a new one. Those copies stay there until you delete them.
Start with Windows
A value named NetworkSpeedMonitor under HKEY_CURRENT_USER\Software\Microsoft\Windows\CurrentVersion\Run. It needs no administrator rights.
Exporting
Exporting the report to CSV writes a file only where you choose to save it.

Deleting your data

  • In the app: open the report and choose Clear all history…. To clear a single adapter or Wi-Fi network, right-click its row on the Adapters or Wi-Fi networks tab.
  • With the uninstaller: an interactive uninstall asks whether to also delete your usage history. A silent uninstall (for example with /VERYSILENT, or through winget once the package is published) always keeps it.
  • By hand: exit the app, then delete the folder %LOCALAPPDATA%\NetworkSpeedMonitor.

This website

These are static pages hosted on GitHub Pages. They set no cookies, run no analytics, and load nothing from any other site: the fonts are served from here too. The scripts here only run the taskbar replica on the home page and the Copy buttons on Verify a download; they send nothing.

GitHub, as the host, may keep standard server logs of visits, such as IP addresses. That is covered by GitHub’s privacy statement, not by this project.
