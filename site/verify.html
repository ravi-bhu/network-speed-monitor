Verify a download

The installers aren’t code-signed yet. Until they are, you can check that the file you downloaded is exactly the one the release published, by comparing its SHA256 hash with the list that comes with every release.

Why it isn’t signed yet

Signing will come through the SignPath Foundation, which signs open-source projects for free. The project applied on 19 October 2026, after the first release, and is waiting for a reply. Until it’s approved, releases are unsigned.

Once signing is on, the app and both installers are signed before the hashes are written, so SHA256SUMS.txt lists the signed files.

Check the hash

  1. From the release page, download the installer, x64 or ARM64, and SHA256SUMS.txt into the same folder.
  2. Open PowerShell in that folder: open the folder in File Explorer, type powershell in the address bar and press Enter.

  3. Run this for the x64 installer:

    Get-FileHash .\NetworkSpeedMonitor-0.1.0-x64-setup.exe -Algorithm SHA256

    Or this for the ARM64 installer:

    Get-FileHash .\NetworkSpeedMonitor-0.1.0-arm64-setup.exe -Algorithm SHA256
  4. Open SHA256SUMS.txt in Notepad. Find the line that ends with the installer’s name, and compare the long string at its start with the Hash that PowerShell printed. PowerShell prints capital letters and the file uses lower case; that isn’t a difference.

If every character matches, the file you have is byte for byte the one the release published: it wasn’t damaged or swapped on the way to you. If it doesn’t match, don’t run it. Download it again, and if it still doesn’t match, open an issue.

A match doesn’t prove the code is safe. It tells you the file is the one built and published by the release workflow, from source you can read. And since the installer and the hash list come from the same release page, it can’t catch someone who could change that page. A signature, once signing is on, doesn’t depend on the release page.

The SmartScreen warning

When you run an installer that isn’t signed and hasn’t been downloaded by many people yet, Windows may show a blue window titled “Windows protected your PC”. It means Microsoft Defender SmartScreen doesn’t recognise the app. It doesn’t mean it found anything harmful. Your browser may warn you when you download the file, for the same reason.

At first the window offers only Don’t run. To go ahead:

  1. Check the hash first, as above. That’s the point: the warning is about a file Windows doesn’t know, and the hash tells you it’s the file the release published.
  2. Select More info. The window then shows the file name and “Unknown publisher”.
  3. Select Run anyway.

If you’d rather not run an unsigned installer, wait for a signed release.

Code signing policy

Free code signing provided by SignPath.io, certificate by SignPath Foundation. Applied for; until it’s approved, releases are unsigned.

Once it’s approved, only the installers and the app built by this repository’s release workflow, from the tagged source, will be signed, and every signing request will be approved by hand.
