Changelog

What changed in each release, newest first. Each one links to its GitHub release, where you’ll find the installers and SHA256SUMS.txt.

Version 0.1.0

Released 19 October 2026

The first release.

  • Installers for x64 and ARM64, for Windows 10 and 11. They install for your user account only, so they need no administrator rights.
  • The taskbar readout: upload and download speed every second, and an optional one-minute graph, in your taskbar’s light or dark theme. Bytes or bits, arrows or U/D letters, the primary taskbar or all of them.
  • Automatic adapter mode, which follows your internet traffic, or one adapter of your choice.
  • The usage report, with Summary, Timeline, Adapters and Wi-Fi networks tabs, nine periods and a custom range.
  • Renaming and hiding adapters, and clearing the history of one adapter, one network or everything.
  • CSV export. Names that a spreadsheet could run as a formula are written as text.
  • Usage history in hourly rows for 90 days, then daily.
  • Starts with Windows, which you can turn off in Settings.
  • The release workflow stops if the app imports Winsock, WinHTTP, WinINet or URLMon.

Not in this release: code signing, which has been applied for, and the winget package.
