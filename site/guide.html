The readout

After you install it, the readout sits on your taskbar, next to the notification area. The top line is your upload speed and the bottom line your download speed, updated every second. The small graph beside them shows the last minute. It follows your taskbar’s light or dark theme.

Hover over it to see which adapter it’s counting. Left-click it to open the usage report. Right-click it for the menu.

The right-click menu

Adapter
Automatic, the default, follows whichever adapter carries your internet traffic, and switches when that changes. Or pick one adapter to see only its traffic.
Units
Bytes per second, the default, or Bits.
Show graph
Shows or hides the one-minute graph. On by default.
Use letters (U/D)
Labels the lines U: and D: instead of arrows.
Open report…
Opens the usage report, the same as a left-click.
Settings…
Opens the settings window, described below.
Exit
Closes the app. Nothing is recorded while it’s closed.

Settings

Settings… on the menu opens a small window with the same options as the menu, and a few more:

  • Start with Windows, on by default.
  • Adapter, Units, Show mini graph and Use letters (U/D), as on the menu.
  • Show on: Primary taskbar only, the default, or All taskbars if you use more than one monitor.
  • Manage adapters… saves your changes and opens the report on its Adapters tab.
  • Open data folder opens %LOCALAPPDATA%\NetworkSpeedMonitor, where your history and settings are kept.

At the bottom are the version number and a Source code link, which opens the project on GitHub in your browser.

The usage report

Left-click the readout, or choose Open report…, to see how much data you’ve used.

Periods

The period picker offers Today, Yesterday, This week, Last week, This month, Last month, Last 30 days, This year, All time and Custom range…, which asks for a start and end date. The report opens on This month. Weeks start on the day your Windows region settings say they do.

Tabs

Summary
Totals for today, this week, this month and the period you picked, then your busiest day in the period, and your top three adapters and Wi-Fi networks.
Timeline
Received and sent data as bars. Each bar is an hour for periods up to 25 hours long, a day for periods up to 92 days, and a month for anything longer. A short period that starts more than 90 days ago gets day bars, because hourly rows aren’t kept that long. Hover over a bar to see its numbers.
Adapters
Received, sent and total data for each adapter. Click a column heading to sort by it.
Wi-Fi networks
The same for each Wi-Fi network you used. Traffic on a network Windows couldn’t name is listed as Unknown Wi-Fi network.

Summary and Timeline count your internet traffic once. The Adapters and Wi-Fi networks tabs count each adapter’s own traffic, so, as the report says, their rows can add up to more than your internet total: a VPN and the Wi-Fi it runs over both count.

What gets recorded

The app records your usage in hourly rows while it runs. Hourly rows are kept for 90 days, then rolled up into one row per day. Traffic while the app isn’t running is not counted, so a day when it was closed shows less than you used.

Renaming, hiding and clearing

On the Adapters tab, right-click an adapter, or select it and press Shift+F10, for these:

Rename…
Gives the adapter a name of your own. The new name shows in the report, on the menu and when you hover over the readout. Leave the name empty to go back to the Windows name.
Hide
Takes the adapter out of the Adapters tab, the Summary’s top adapters and the right-click Adapter list. Nothing is deleted, and its traffic still counts in your internet totals. To bring it back, tick Show hidden adapters, right-click it and choose Unhide.
Clear this adapter’s history…
Deletes everything recorded for that adapter.

On the Wi-Fi networks tab, right-click a network for Clear this network’s history…. To delete everything, use Clear all history… at the top of the report. The app asks before it clears anything, and a clear can’t be undone.

Exporting to CSV

Export CSV… in the report saves the selected period to a file you choose, for every adapter and network. The file is UTF-8 text with one row per hour, or per day for history older than 90 days. It has these columns:

ColumnWhat it holds
start_localWhen the hour or day starts, in your local time: 2026-10-19 14:00 or 2026-10-19.
granularityhour or day.
seriesinternet or adapter, explained below.
adapter_idThe ID Windows gives the adapter, a GUID in braces.
adapter_nameYour name for the adapter if you renamed it, otherwise the Windows name.
adapter_kindwifi, ethernet, virtual or other.
networkThe name Windows gives the network; for Wi-Fi, usually the network’s own name. Empty when Windows has no name for it.
received_bytesBytes received in that hour or day.
sent_bytesBytes sent in that hour or day.

The series column says what a row counts. internet rows are your internet traffic, through whichever adapter carried it. adapter rows are each adapter’s own traffic, so a VPN and the Wi-Fi it runs over both count. The two overlap, so don’t add up rows across series: filter on one first. The internet rows match the report’s headline numbers.

Network and adapter names come from outside the app; anyone can name a Wi-Fi network. So a name that starts with =, +, -, @, a tab or a carriage return is written with a ' in front. Spreadsheets then show it as text instead of running it as a formula.

Starting with Windows

The app starts when you sign in to Windows. That’s on by default. To turn it off, open Settings… from the right-click menu and untick Start with Windows.

The setting is a value named NetworkSpeedMonitor under HKEY_CURRENT_USER\Software\Microsoft\Windows\CurrentVersion\Run, so it needs no administrator rights.

Uninstalling

Open Settings, then Apps, and find Network Speed Monitor under Installed apps (Apps & features on Windows 10). Choose Uninstall.

The uninstaller closes the app if it’s running, then asks whether to also delete your usage history. No is the default; Yes deletes the %LOCALAPPDATA%\NetworkSpeedMonitor folder, with your history and settings. A silent uninstall, such as one run by winget, always keeps it. Either way, the Start with Windows entry is removed.

If you kept the history and want it gone later, delete that folder yourself.
